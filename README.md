# 🔄 Data Flow Diagrams (DFD)
# 📌 Task Objective

The objective of this project is to analyze and represent the flow of data within different information systems by creating Data Flow Diagrams (DFDs). This helps in understanding how data moves between processes, data stores, and external entities within a system.

# 🛠️ Tasks Performed

Designed Data Flow Diagrams for multiple systems

Identified external entities involved in each system

Defined system processes and data flows

Created data stores for storing system information

Developed Level 0 (Context Diagram)

Developed Level 1 DFD for detailed process flow

Represented data movement between system components for:

Student Enrollment System

Library Management System

Online Shopping System

# 📂 Deliverables

Context Level DFD

Level 1 DFD Diagrams

System Process Representation

Data Flow Visualization

# 📚 Technologies Used

System Analysis and Design Concepts

Data Flow Diagramming

Diagram Design Tool (e.g., Draw.io / Lucidchart)
